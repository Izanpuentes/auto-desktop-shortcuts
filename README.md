# auto-desktop-shortcuts

Herramienta para Ubuntu (GNOME + Desktop Icons NG) que detecta las aplicaciones
instaladas y permite crear accesos directos en el escritorio, como en Windows.

## Objetivo

- Detectar las apps instaladas por apt, Snap y Flatpak (y los juegos de Steam).
- Al instalar una app nueva, preguntar si se quiere crear su acceso directo.
- Crear el acceso directo listo para usar (ejecutable y marcado como de confianza).
